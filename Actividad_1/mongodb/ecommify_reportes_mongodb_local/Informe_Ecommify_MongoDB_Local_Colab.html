Informe Ecommify - Actividad 1 MongoDB Local en Google Colab

Resumen Ejecutivo

Se creó una base de datos MongoDB local dentro de Google Colab para la plataforma Ecommify. El notebook cargó datos desde Google Drive, creó colecciones documentales, implementó índices compuestos, parciales y de texto, ejecutó consultas con explain executionStats, desarrolló pipelines de agregación y generó evidencias cuantitativas.

Conclusión
